# 🚀 PMBus Device Manager & Telemetry Tool
Приложение Python/Tkinter для поиска устройств PMBus, телеметрии, настройки и работы с дампами регистров.

## 📋  Поддержка

| Модель | Каналов | VIN | VOUT | IOUT макс |
|:---:|:---:|:---:|:---:|:---:|
| **LTM4673** | 4 | 4.5–16V | 0.5–5.5V | 8A |
| **LTM4677** | 2 | 4.5–16V | 0.5–1.8V | 18A |
| **LTM4678** | 2 | 4.5–16V | 0.5–3.4V | 25A |

## ⚙️ Настройка интерфейсов и библиотек

Приложение автоматически определяет тип подключения на основе выбранного ID шины:

| Bus ID | Адаптер | Библиотека | Команда установки |
|:---:|:---|:---:|:---|
| **0–99** | Локальная шина `/dev/i2c-N` (Linux) | `smbus2` | `pip install smbus2` |
| **100–199** | USB-I2C адаптер CH341T/A (VID 1a86:5512) | `pyusb` | `pip install pyusb` |
| **200–299** | Адаптеры FT232H / FT2232H / FT4232H | `pyftdi` | `pip install pyftdi` |

• CH341T и FT232H – на LTM4678 проверены поиск, чтение, мониторинг и переподключение.

• CP2112 – реализован, аппаратная проверка не завершена.
• /dev/i2c-N - пока не поддерживается

Запись VOUT_COMMAND проверена на LTM4678. Силовые испытания LTM4677 приостановлены из-за неожиданных показаний тока. Поддержка модели не означает аппаратной проверки всех операций.

## 🚀  Запуск

Используйте окружение Python с Tkinter и установите зависимости.

```bash
python -m pip install -r requirements.txt hidapi
```
```bash
python main.py
```
Для оборудования также нужны права доступа к USB, подходящий драйвер и системные библиотеки, включая libusb для PyUSB.
Деморежим без адаптера, только для чтения.
```bash
python main.py --demo
```
Телеметрия в demo синтетическая. При запуске пока проверяются Python-зависимости USB даже в деморежиме.

### Config

Синяя стрелка читает регистр и заменяет ввод.
Зелёная записывает после подтверждения. 
Read All спрашивает перед потерей изменений.
Мониторинг обновляет телеметрию и статусы, но не Config.

Поля L11/L16 используют инженерные значения, остальные числовые поля – RAW hex с 0x.

OPERATION и ON_OFF_CONFIG имеют профильные списки. Значения вне списка отображаются без нормализации.

Preview подготавливает изменения без аппаратного I/O.
Пакетное применение разрешено только для VOUT_COMMAND, проверяет исходные значения и точное совпадение RAW после записи. OPERATION, ON_OFF_CONFIG и WRITE_PROTECT записываются индивидуально.

Индивидуальные записи OPERATION и ON_OFF_CONFIG также требуют точного совпадения readback.

Для остальных индивидуальных записей общее сравнение RAW не выполняется. Ошибка чтения или попытки записи сбрасывает baseline затронутого поля; при неудачной попытке записи запрошенный ввод сохраняется.
Контекстно-зависимые кодировки OPERATION у LTM4673 пока запрещены. Прочитанное значение регистра не подтверждает физическое состояние выхода.

### CSV, NVM и отключение

Для загрузки CSV обязательна корректная SHA-256. Файлы без суммы или с несовпадением отклоняются. Повторный экспорт сохраняет исходные метаданные. Перед записью дампа проверяются выбранные записи и совместимость с устройством. Контрольная сумма не подтверждает подлинность источника или безопасность для платы.

Запись дампа и сохранение/восстановление NVM выполняются отдельно. Автоматического отката и автоматического сохранения в NVM нет. Аппаратная проверка этих операций проводится отдельно от обычных записей RAM.
Обнаруженное отключение адаптера останавливает мониторинг и помечает Config как устаревший. После подключения используйте Refresh и Scan. Блокировки не допускают конфликтующих ручных действий, в том числе между вкладками устройств.

## Структура проекта

• core/drivers – транспорты адаптеров.

• core/devices – профили устройств и правила значений.

• core/pmbus_device.py – доступ к регистрам и проверка записи.

• gui/profiles – размещение телеметрии и Config.

• gui/config_notebook.py – редактор Config.

• gui/status_defs.py – расшифровка статусов.

## Безопасность

Перед записью проверьте модель, адрес, страницу и ограничения платы.
Сохраните исходные значения и используйте контролируемый стенд.
Не применяйте общие и широковещательные адреса для проверки отдельного устройства.
Проверяйте настройки RAM до сохранения в NVM.
